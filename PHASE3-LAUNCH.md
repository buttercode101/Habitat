# Phase 3 launch brief

## Positioning
An agent says DONE. Habitat separates the claim from what the evidence can actually prove.

## ICP
AI-agent builders and engineering teams already using traces/CI but needing portable evidence for consequential agent actions and handoffs.

## Activation
Inspect a proof -> tamper with evidence -> see integrity fail -> understand the assurance boundary.

## North star
Consequential agent claims backed by independently inspectable Habitat proof artifacts.

## Monetization
Open-source core first. Validate repeated proof creation/verification before team dashboard, hosted history, policy packs or enterprise controls.

## Experiments
1. Technical case study: valid artifact vs unverified external truth. Success: developers inspect/tamper with proof. 14 days.
2. GitHub integration example around one CI/deployment claim. Success: external repo reproduces it. 30 days.
3. Compare against tracing tools: “logs show activity; proof states what evidence supports.” Success: qualified developer installs, not impressions.

## Launch copy
**One line:** Habitat turns “the agent says it happened” into an inspectable claim with an explicit evidence boundary.

## Evidence log
External truth is never inferred from artifact integrity alone. Users/revenue: 0 verified here.
